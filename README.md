# Monthly Complaints Report

North Star Housing Group. A single-page tool that turns an HMS Endeavour complaints export into the monthly report (five questions, evidenced thresholds, exceptions first, postcode map).

## How to use
1. Open the site.
2. Data tab: load the Endeavour complaints export (.xlsx or .csv). Optionally load the satisfaction export and the monthly jobs workbook.
3. Report tab: review, complete the "things to complete before clinic/MRC" list, then Download report.

## Privacy
The files you load are processed in your browser only. Nothing is uploaded or stored by this site, and no real data is included in this repository.

## Publish with GitHub Pages
Settings > Pages > Deploy from a branch > main / root.

Postcode outlines: Wikipedia postcode district polygons (CC BY-SA) via missinglink/uk-postcode-polygons, simplified.
